## 3. 科学问题与技术路线

### 3.1 三个科学问题（写进说明书"关键技术问题"栏）

1. **产氢侧**：可见光下催化剂浓度、光强、pH、温度对产氢速率的影响规律是什么？（响应面法建模）
2. **传质侧**：产生的 H₂ 从液相本体 → 气液界面 → 气相的**溶解—逸出耦合传质**如何随搅拌、温度、系统密封性变化？溶解氢浓度的**衰减动力学**如何？
3. **应用侧**：在上述条件下制得的富氢水，其溶解氢浓度能否稳定达到行业常用的 **1.0–1.6 ppm** 区间？对细胞氧化应激指标是否呈现可测量的改善（探索性）？

> 💡 第 2 点是**你的理论护城河**。大多数参赛队只会报"产氢速率多少"，你能给出"产氢—溶解—逸出"三段耦合的模型与实测拟合，学术水平立刻拉开档次。

### 3.3 量化指标（写进申报书"主要技术指标"）

| 指标 | 目标值 | 对标/说明 |
|---|---|---|
| 产氢速率 | ≥ 500 μmol·g⁻¹·h⁻¹（借用催化剂的典型值附近） | 说明书写实测值 + 与文献同类型催化剂对比 |
| 富氢水溶解氢浓度 | ≥ 1.0 ppm，最高 ≥ 1.5 ppm | 行业常用区间 1.0–1.6 ppm |
| 浓度半衰期（敞口/密封） | 实测给出，目标密封下 ≥ 30 min | 这是传质建模的核心输出 |
| 响应面模型 R² | ≥ 0.90，预测误差 ≤ 10% | Box-Behnken + ANOVA |
| 装置成本 | ≤ 1500 元 | 经济性评审看这个 |
| 运行功耗 | ≤ 20 W（LED 光源为主） | 便携性叙事的支撑 |
| （可选）细胞 ROS 清除率 | 相对对照改善 ≥ 15% | 探索性，写"初步""趋势"，不写"治疗" |

## 11. 为什么把"氢分子医学"降级为应用前景（诚实的自我修正）

> 用户原话：*"讲一下氢分子医学，这个领域和本竞赛有什么关系？本竞赛不是能源类竞赛吗？"* —— 这个质疑是对的，本节正面回答，并据此修正推荐。

### 11.1 氢分子医学是什么

**定义**：研究氢气（H₂）作为**生物活性分子**对疾病防治作用的新兴领域。核心假说是：H₂ 能**选择性中和最强的两种细胞毒性自由基**（羟基自由基 ·OH、过氧亚硝酸阴离子 ONOO⁻），而不干扰信号转导所需的活性氧（NO·、H₂O₂ 等），从而起到"选择性抗氧化"效果；后续研究还指向 Nrf2 通路、线粒体功能、细胞凋亡与炎症调控等机制。

**关键里程碑**

| 年份 | 事件 |
|---|---|
| 1975 | Dole 等在 *Science* 报道高压氢气（8 atm）抑制小鼠皮肤鳞状细胞癌——最早的氢生物医学实验 |
| **2007** | **Ohta 等在 *Nature Medicine* 发表"吸入 2% 氢气选择性清除细胞毒性氧自由基"**——现代氢医学的起点 |
| 2008 前后 | 富氢水、氢盐水、氢浴等给药方式陆续出现 |
| 2010s | 临床/前临床扩展：脑卒中、心肌缺血再灌注、肝肾损伤、放射性损伤、脓毒症、代谢综合征、运动疲劳、皮肤修复等 |
| 2018 | 中国氢学会首次颁发"中国氢生物医学突出贡献者奖"给三位学者（含北工大马雪梅） |

**给药方式**：吸入氢气（1–4%）、**富氢水**（溶解氢约 0.4–1.6 ppm，即本项目的产品形态）、氢盐水、氢浴、镁基产氢材料/敷料。

**中国研究群体**：孙学军（海军军医大学）、秦树存（山东第一医科大学）、**马雪梅（北京工业大学，"氢分子生物医学"概念的提出者之一，中国老年保健医学研究会氢分子生物医学分会副主任、长三角氢健康发展研究院院长）**、**谢飞（北工大，氢气与纳米材料在肿瘤、脑科学中的应用）**。

**必须知道的争议**：样本量普遍偏小、机制尚未完全定论（是"直接抗氧化"还是"信号调控"仍有争论）、部分临床试验结果不一致、**商业化富氢水产品的功效宣称已被监管收紧**。所以写进说明书时只能用"初步评估""探索性""文献报道表明"这类措辞，**绝不能写"治疗""疗效"**。

### 11.2 它和这个竞赛的真实关系：**不是主线，是链条最末端的一个分支**

可再生能源产业链是：

```
可再生能源发电  →  制氢  →  储氢  →  输氢  →  用氢
（光伏/风电）    （光催化/    （高压/      （管道/    ┌─ 能源用途：燃料电池、燃烧、化工合成
                电解水）   金属氢化物）   载体）    └─ 生物用途：氢医学、氢农业、氢生物制造 ← 氢分子医学在这
```

- 竞赛官网《竞赛简介》**确实**把"氢能"列为竞赛内容，报名系统技术领域也有"氢能"——所以**氢能是官方赛道**。
- **但**评审是中国可再生能源学会的**能源领域专家**，他们看"氢能"看的是制氢、储氢、燃料电池、氢化工。**氢医学在他们眼里是陌生甚至可疑的**。
- 往届获奖作品可以佐证：氢能方向的获奖作品全部是"甲醇水解制氢催化剂""高温固体氧化物燃料电池""氢气检测装置"这类**纯能源/化工**题目，**没有一件是氢医学**。这不是巧合，是评审口味的直接体现。

### 11.3 由此对项目推荐的修正

| 原推荐 | 修正后 |
|---|---|
| 标题含"富氢水""抗氧化效应""细胞效应" | 标题主体是**装置 + 传质建模**；"富氢水"只作产品名，不作医学宣称 |
| 生物效应是三大科学问题之一 | 生物效应**降为"应用前景分析"中的一段展望**（≤300 字），不做实验、不进结论 |
| 双导师：孙再成 + 谢飞/马雪梅 | **主导师孙再成**（能源侧）；谢飞/马雪梅仅作应用前景部分的把关，可不挂名 |
| 说明书第 E 段做细胞实验 | **删除该段**，改为文献引用 + 展望 |

**修正后最稳的题目**：《可见光催化分解水产氢装置的研制及产氢—溶解氢传质耦合动力学建模》（题目③）。它 100% 在赛题内，零跑题风险，而"产氢—溶解氢传质耦合建模"这个理论点足以撑起学术水平。

### 11.4 那氢分子医学这条线还有什么用？——**用在别处，才是它的主场**

| 赛道 | 什么时候 | 为什么氢医学在那里是加分项 |
|---|---|---|
| **生医工创新设计竞赛** | 大二下（2028 春） | 这是**你的对口 B 类赛**，评审就是生医工教指委+生物医学工程学会，氢医学是正经的生物医学问题，**+1.5 分** |
| **挑战杯 / 互联网+** | 大二下—大三 | 这两个赛**奖励交叉创新**，"光催化制氢 × 氢分子医学"是漂亮的医工交叉叙事，且国赛奖项上浮认定 |
| **国家级大创** | 大二上 | 以氢分子生物医学为题申报，用马雪梅/谢飞的平台做深（动物/细胞实验），结题 **+1 分** |
| **论文** | 大三 | 氢分子医学有真实的发表空间（*Medical Gas Research* 等），可与孙再成的制氢工作合写"产氢—应用"贯通论文 |

**一句话总结**：在可再生能源竞赛里，氢分子医学只能是**应用前景里的一句展望**；但一旦你把这条线带到生医工竞赛、挑战杯和大创，它就是**你的核心竞争力**。同一个装置，换个赛场讲不同的故事——这才是这条缝合线的正确用法。
