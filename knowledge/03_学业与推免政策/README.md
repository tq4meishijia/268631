# 北工大保研竞赛资料研究项目

本项目整理北京工业大学（生医工方向）保研相关竞赛规则、奖学金体系与推免途径的公开资料，包含官方竞赛认定目录、环境与生命学部实施细则、推免办法发文原件，以及据此产出的分析文档。

### 目录说明
- `docs/`：结论性笔记与项目总览（Markdown 文档）。其中 `北工大奖学金与保研途径-深度调研.md` 为现行制度基准，与旧稿冲突时以它为准。
- `research/`：官方原始参考资料（PDF 原文、全文提取文本、细则压缩包）、公开信息采集数据与结构化调研产物。
- `research/tools/`：可复现的栏目列表抓取与详情解析产物，无第三方依赖。`scripts/` 为脚本、`data/` 为抓取数据、`shots/` 为过程截图。
- `_archive/`：旧稿存档位（当前存有全景图重写前的 v1 旧稿）。

> 说明：`research/` 为本项目自定义分类，对应通用工程规范中 `data/` 的角色。
