Comparative Analysis

三个候选题目的系统对比与量纲匹配检验

三个题目技术内核完全相同——都是"桌面级光催化产氢装置 + 产氢—溶解氢传质耦合动力学建模"，差异只在应用外壳与叙事。风险 90% 来自叙事层，不来自技术层。

★

02量纲匹配硬检验（本文最有价值的一节）

三个题目的应用承诺，所需的氢气量差 2–3 个数量级。先把装置的供氢能力算清楚，再拿它去量应用。

第一步：装置能给多少氢？

催化剂负载 0.1 g × 产氢速率 500 μmol·g⁻¹·h⁻¹ = 50 μmol·h⁻¹
50 μmol·h⁻¹ × 22.4 mL·mmol⁻¹ ≈ 1.12 mL H₂ / 小时（标况） 参考量级：含牺牲剂（甲醇/TEOA）体系 200–2000 μmol·g⁻¹·h⁻¹；全分解水（纯水，无牺牲剂）仅 1–100 μmol·g⁻¹·h⁻¹。 放大催化剂负载或聚光可提升，但数量级不变。

第二步：三个应用各要多少氢？

应用需氢量换算到本装置匹配度
① 富氢水
1.0–1.6 ppm		 1 L 水需 11–18 mL H₂
（0.5–0.8 mmol）		 1 L 需 10–16 小时 量级匹配 ✅
② 便携供氢
燃料电池 / 应急用氢		 小型燃料电池 600–6000 mL/h
（10–100 mL/min）		 本装置差 500–5000 倍 严重不匹配 ❌
③ 光催化产氢
无应用承诺		 不承诺应用 不需量纲论证 不涉及 ✅

第三步：这道检验带来的三个判断

  1. ①其实是最"技术上成立"的应用——富氢水所需氢气量极小（1 ppm 只要 11 mL H₂/L 水），恰好是光催化微量产氢的天然出口。讽刺的是：应用匹配度最高的是跑题风险最高的那个。
  2. ②的"便携供氢"在工程上站不住——除非把定位改成"微流量供氢 / 教学演示 / 小型传感器供氢 / 分布式演示单元"，或做聚光 + 大面积反应器的放大论证。否则评审一句"你这 1 mL/h 能带什么"就把项目问倒了。
  3. ③避开了整个量纲问题——不承诺应用，就没有"产氢量够不够"的追问。这是它"最稳"的深层原因，不只是因为标题不跑题，更因为它不欠一笔技术债。
i

给选 ② 的补救方案：在说明书写一节"供氢能力与应用场景的量纲匹配分析"，明确装置定位为小流量分布式制氢单元，并给出放大路线（聚光倍率、催化剂负载、反应器面积 → 产氢量放大曲线）。现场答辩主动把"1 mL/h"讲成"模块化堆叠可扩展"，把短板变成设计思路。

06分场景推荐：同一装置，换赛场讲不同故事

场景首选题目理由
本赛：可再生能源竞赛③（或 ② 补量纲论证）能源评审 + 零跑题 + 零技术债 + 工作量最小
生医工创新设计竞赛（大二下，+1.5 分）①评审是生医工教指委，富氢水/氢分子生物医学是正经生物医学问题
挑战杯 / 互联网+（大二下—大三）①（加商业叙事）奖励医工交叉，国赛奖项上浮认定
国家级大创（大二上）①（加细胞/动物实验）用马雪梅/谢飞平台做深，结题 +1 分
论文投能源类期刊③传质建模是硬核理论点，能源期刊认可
论文投生物医学 / 氢医学期刊①Medical Gas Research 等接受氢分子生物医学
★

最终推荐：本赛选 ③。理由（按决定性排序）：零跑题 → 零技术债 → 工作量最小 → 创新点最硬 → 同一内核可复用到大二的医工交叉外壳，一鱼两吃。

一句话记住：评审是什么人，作品就讲什么故事。本赛是能源评审 → 讲能源内核（③）；生医工赛是医学评审 → 讲医工外壳（①）。
