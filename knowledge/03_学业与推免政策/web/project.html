02两个科学问题

第二个问题是你真正的护城河——大多数参赛队只报产氢速率，你能给出三段耦合模型并实测标定。

科学问题 1 · 产氢侧

可见光产氢的多因素响应规律是什么？

催化剂浓度、光强、pH、温度四个因素如何共同决定产氢速率？交互作用是否显著？

方法：Box-Behnken 响应面实验设计（9–15 组）+ ANOVA + 三维响应面图。

科学问题 2 · 传质侧（护城河）

产氢—溶解—逸出三段耦合传质如何建模？

产生的 H₂ 从液相本体 → 气液界面 → 气相的传质过程如何随搅拌、温度、密封性变化？溶解氢浓度的衰减动力学如何？

方法：双膜传质 + Henry 溶解度 + 生成速率 → 用实测衰减曲线拟合 kLa，给 R² / RMSE / 误差分布。

传质模型骨架

dCH₂/dt = Rgen(I, [cat], pH, T) − kLa · (CH₂ − C*)
C* = H−1 · pH₂　（Henry 定律，气液平衡浓度） 其中 Rgen 为光催化产氢本征速率（由响应面模型给出），kLa 为液相体积传质系数，C* 为平衡溶解浓度。 实测：溶解氢浓度随时间的衰减曲线 → 最小二乘拟合 kLa → 模型预测 vs 实测，报 R²、RMSE、误差分布。

05创新点（写进说明书的那一段）

理论创新

产氢—溶解氢—逸出三段耦合传质建模

把"光催化产氢"与"气液传质"两个常被分开处理的问题耦合起来，用双膜传质 + Henry 溶解度 + 生成速率构建统一模型，并以实测衰减曲线标定 kLa。

这是唯一护城河，必须做实：模型形式 → 参数辨识 → 误差评估 → 与文献实测对比。

工程创新

装置集成氢浓度实时监测

把集气、溶解氢检测、温度/光强采集集成到一个桌面单元，实现"产氢速率 + 溶解氢浓度"双通道实时输出，而不是事后化验。

装置照片、系统框图、采集界面截图都是说明书必交的图件。

应用创新

面向小流量供氢场景的一体化与经济性设计

给出成本、功耗、体积与产氢能力的量纲匹配分析，明确装置定位为小流量分布式制氢单元（演示、教学、小型传感器供氢），并给出模块化放大的路线。

这一节是答辩时把"产氢量小"变成"设计思路"的关键。
