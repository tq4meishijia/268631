# DESIGN.md · 受访者逐一采访纪要（5 页查读型）

## 需求对齐（用户显式约束，优先级高于通用设计默认）

| 维度 | 结论 |
|---|---|
| 主题 | 五位受访者的详细采访纪要 |
| 受众 | 小组内部查阅、横向对比 |
| 页数 | **严格 5 页 = 5 位受访者**；无封面、无目录、无章节页、无结尾页 |
| 分页 | **一人一页，不合并、不拆分**；页面标题即受访者姓名 |
| 每页内容 | 基本信息 / 采访主题与核心问答 / 主要观点及关键引语 / 结论 / 待跟进事项 |
| 结构 | **5 页完全同构**（用户显式要求「统一结构、便于横向对比」），故覆盖通用规范中「相邻页换版式」的软规则 |
| 调性 | 克制、证据驱动、可查读；沿用学院模板的青蓝体系 |

## ① 画布与安全区

- 画布 1280×720；padding 上下左右各 60px；内容区 1160×600。
- 标题带 56px + 间距 16px + 主体 528px = 600px。

## ③ 字体系统

- 中文：Microsoft YaHei；西文：Arial（与学院模板一致）。
- 字号阶梯：姓名标题 34px / 区块标题 20px / 正文 16px / 副标题与页码 16px / 出处 14px。
- **说明**：本 deck 是「一人一页、不拆分」的高密度查读件，正文按「表格／查读内容」层级取 16px（每页正文约 790–910 字）；若改回常规演讲正文 18px，单页将溢出 49–265px，必然要删减关键信息或拆分页面。此处以用户「内容完整、不拆页」约束优先。

## ④ 视觉母题

姓名标题带下的 1px 贯通青线；每个内容区顶部同色细线 + 统一样式的区块标题；右上角固定「内部编号 ｜ 序号 / 05」。
