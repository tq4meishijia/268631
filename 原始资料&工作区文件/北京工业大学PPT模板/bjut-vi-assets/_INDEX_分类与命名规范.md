# 分类与命名规范

本文件定义 `bjut-vi-assets/` 资产库的分类体系、文件命名规则与检索方式。库内 **40** 项资产全部按此规范命名，可据此直接定位、排序与批量引用。

## 一、分类原则

1. **按元素性质分类**，不按来源页面或下载时间分类——同一类元素的不同变体（彩色／墨稿／反白）必须相邻，便于比较取用。
2. **一类一目录**，目录名以两位数字前缀固定排序权重，与类型代码一一对应。
3. **规范与素材分离**：制图规范页归入 `10_使用规范`，不与被规范的对象混放。
4. **院级与校级分离**：二级学院沿用校 VI 体系，但作为独立主体单列，避免与校级标识混淆。

## 三、命名规则

```
{主体}-{类型}{序号}_{变体}_{描述}.{扩展名}
```

| 字段 | 取值 | 说明 |
|---|---|---|
| 主体 | `BJUT` / `HS` | 北京工业大学 / 化学与生命科学学院 |
| 类型 | 见上表 12 个代码 | 决定所属目录 |
| 序号 | 两位数字 `01`–`99` | 同类内流水，新增资产顺延，不复用已废弃编号 |
| 变体 | `C` `K` `W` `P` `N` | 彩色 / 墨稿 / 反白 / 预览 / 通用 |
| 描述 | 中文，用 `-` 连接 | 仅写区分性信息，如「横式」「科学楼」「单体形象」 |

**示例**

| 文件名 | 解读 |
|---|---|
| `BJUT-EM01_C_校徽.svg` | 校级 · 校徽 · 第 1 组 · 彩色 |
| `BJUT-LK01_W_校标中英文-横式.svg` | 校级 · 组合标识 · 横式 · 反白 |
| `HS-LK01_W_院名组合-横式.png` | 化生学院 · 组合标识 · 横式 · 反白 |
| `BJUT-GF02_N_辅助图形一-奥运体育馆.svg` | 校级 · 辅助图形 · 第 2 组 · 通用 |

## 四、资产编号

清单中的**资产编号**＝文件名去掉变体与描述，即 `主体-类型序号-变体`，如 `BJUT-EM01-C`。

- 编号与文件**一一对应**：同一编号下 `.svg` 与 `.png` 是同一矢量的两种载体，不是两个资产。
- 编号唯一且稳定：同名文件被替换时编号不变，仅在清单「备注」记录变更。
- 一个资产可含多个文件（矢量＋位图），在清单「文件」列以 ` ; ` 分隔。

## 五、命名禁忌

- 不写尺寸数字（`1920x500` 之类）——尺寸会随替换失效，登记在清单「分辨率/尺寸」列。
- 不写日期或版本号——版本信息由编号稳定性＋备注承担。
- 不用空格、中文括号、`+` 号——避免命令行与 Web 引用时的转义问题。
- 同类资产不并列两个中文词做前缀（如「校徽校标」）——必须拆到不同类目。

## 六、检索方式

- **按类型**：直接看目录前缀数字，`01`–`11` 即类型顺序。
- **按编码**：文件名前 8 位含主体与类型，`dir /b | sort` 即可聚合同类。
- **按场景**：白底用 `_C_`；单色印刷用 `_K_`；深底或图片上用 `_W_`。
