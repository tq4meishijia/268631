## 做了什么

针对"北京工业大学大一生物医学工程专业学生，哪些竞赛对保研有帮助"这一问题，从学校官方原始文件出发做了完整核查，而非依赖通用经验：

1. **抓取并解析官方原始文件**
   - 教务处《北京工业大学本科生科技竞赛认定目录（2023版）》A类 PDF（72项，7页）全文提取
   - 同版 B类 PDF（32项）全文提取
   - 附件5《各学部（院）B类竞赛管理实施细则》zip，定位并解析**环境与生命学部**细则（生医工适用）
   - 《北京工业大学推荐优秀应届本科毕业生免试攻读硕士学位研究生的实施办法》加分条款

2. **产出交付物**
   - `北工大生医工-保研竞赛全景图.md`：规则解读 + 竞赛三梯队清单 + 三年倒计时表 + 组队选题 + 待补信息清单

## 关键结论（与直觉相反的三点）

| 发现 | 影响 |
|---|---|
| 全国大学生生物医学工程创新设计竞赛在北工大是 **B类**（非A类），国家级一等奖仅 +1.5 分 | 最对口的赛不能当主攻，只能当保底 |
| 美赛（MCM/ICM）在环境与生命学部 B类细则中"保研加分适用专业"= **应用化学**，不含生医工 | 生医工打美赛不加分 |
| 蓝桥杯在北工大 A类目录中认定级别是 **省部级**，省部级二等奖及以下 0 分 | 别把蓝桥杯当保研主攻 |
| 互联网+/挑战杯×2 标注"国家级*"，国赛奖项**上浮一级**认定（国赛二等奖 = 一等奖 = +3） | 全表性价比最高的加分路径 |
| 科技创新加分"仅认定一项、不累加、上限4分" | 广撒网刷分在北工大无效，必须集中火力 |
| 硬截止 = 推免当年 **8月31日**（该生为 2029-08-31） | 大三下是最后窗口 |

另发现口径冲突：推免办法写"认定前三人"，竞赛目录尾注写"认定前五人"——已在报告中标注需向学院教务核实，并给出安全做法（署名站进前三）。

## 决策与方法

- 用 pypdf 在隔离 venv 中解析 PDF，未污染系统环境
- 所有分值/级别均标注"以官方通知为准"，未臆造截止日期与名额数字
- 不编造任何个人经历或成绩，缺失信息一律用方括号占位符
