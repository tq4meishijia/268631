# 三题目系统对比分析 · 可再生能源竞赛选题

> **对比对象**：《项目推荐书》§1 的三个候选题目
> ①《可见光催化富氢水一体化制备装置的研制及产氢—溶解氢传质耦合动力学建模》
> ②《面向便携供氢的可见光催化产氢—溶解氢一体化装置研制与传质动力学建模》（清洁能源应用）
> ③《可见光催化分解水产氢装置的研制及产氢—溶解氢传质耦合动力学建模》（最稳健）
> **分析基准**：2026-10-29｜评审语境 = 中国可再生能源学会能源专家｜交付物 = 说明书 ≤5000 字 + 申报书 + 现场答辩
> **本文目的**：把三个题目在同一套技术内核下拆开看，量化"技术合理性"这个常被忽略的硬约束，并给出分场景推荐

## 0. 结论摘要

| 维度 | ① 富氢水版 | ② 便携供氢版 | ③ 分解水产氢版 |
|---|---|---|---|
| **跑题风险** | **高**（健康/产品叙事） | 低 | **零** |
| **技术合理性（量纲匹配）** | **优**（应用需氢量小） | **差**（差 2–3 个数量级） | 不涉及（无应用承诺） |
| **创新点清晰度** | 中（被应用叙事稀释） | 高 | **最高** |
| **开题被问倒的概率** | 中高 | 中高（"产氢量够吗"） | **低** |
| **实验工作量** | 中（多做浓度稳定性） | 中（多做流量匹配演示） | **最低** |
| **论文/说明书写作难度** | 高（易滑向健康宣称） | 中（应用前景易空洞） | **低** |
| **在本赛的胜率** | 中低 | 中 | **高** |
| **在后续赛道的价值** | **最高**（医工交叉） | 中 | 中 |

**综合推荐**

> **本赛（可再生能源竞赛）选 ③；若评审明显重应用落地与经济性，改 ② 并补量纲论证；① 不用于本赛，留给生医工竞赛/挑战杯/大创。**

**一个必须先说清的关键洞察**：这三个题目**技术内核完全相同**——都是"桌面级光催化产氢装置 + 产氢—溶解氢传质耦合动力学建模"。差异**只在应用外壳与叙事**。所以选择的本质不是"做哪个实验"（实验工作量几乎一样），而是"**向能源评审讲哪个故事**"。风险差异 90% 来自叙事层，不来自技术层。

## 1. 先做一道硬检验：量纲匹配（技术合理性）

这一节是本分析最有价值的部分——**三个题目的应用承诺，所需的氢气量差 2–3 个数量级**。

### 1.1 光催化产氢能给多少氢？

典型可见光光催化产氢速率（借用孙再成组 g-C₃N₄ 基或 TiO₂ 基催化剂）：

| 体系 | 典型产氢速率 | 说明 |
|---|---|---|
| 含牺牲剂（甲醇/三乙醇胺） | 200–2000 μmol·g⁻¹·h⁻¹ | 实验室常用，产氢速率高 |
| **全分解水（纯水，无牺牲剂）** | **1–100 μmol·g⁻¹·h⁻¹** | 严格意义的"光催化分解水"，速率低很多 |

取装置实际参数：催化剂负载 **0.1 g**、可见光 LED、含牺牲剂体系、产氢速率 **500 μmol·g⁻¹·h⁻¹**：

```
0.1 g × 500 μmol·g⁻¹·h⁻¹ = 50 μmol·h⁻¹ ≈ 1.12 mL H₂/h（标况）
```

**约 1.1 mL 氢气/小时**——这是全装置的供氢能力上限（放大催化剂负载或聚光可提升，但数量级不变）。

### 1.2 三个应用各要多少氢？

| 应用 | 需氢量 | 换算到本装置 | **匹配度** |
|---|---|---|---|
| **① 富氢水**（1.0–1.6 ppm） | 1 L 水需 **11–18 mL H₂**（0.5–0.8 mmol） | 1 L 需 **10–16 小时** | ✅ **量级匹配，可实现** |
| **② 便携供氢**（燃料电池/应急用氢） | 小型燃料电池 **600–6000 mL/h**（10–100 mL/min） | 本装置差 **500–5000 倍** | ❌ **严重不匹配** |
| **③ 光催化分解水产氢**（无应用承诺） | 不承诺应用 | 不需量纲论证 | ✅ **不涉及** |

### 1.3 这道检验带来的三个判断

1. **①其实是最"技术上成立"的应用**——富氢水所需氢气量极小（1 ppm 只要 11 mL H₂/L 水），恰好是光催化微量产氢的天然出口。讽刺的是：**应用匹配度最高的是跑题风险最高的那个**。
2. **②的"便携供氢"在工程上站不住**——除非把定位改成"微流量供氢/教学演示/小型传感器供氢/分布式演示单元"，或在说明书中做**聚光+大面积反应器**的放大论证。否则评审一句"你这 1 mL/h 能带什么"就把项目问倒了。
3. **③避开了整个量纲问题**——不承诺应用，就没有"产氢量够不够"的追问。这是它"最稳"的深层原因，**不只是因为标题不跑题，更因为它不欠一笔技术债**。

> 💡 **给选 ② 的补救方案**：在说明书写一节"供氢能力与应用场景的量纲匹配分析"，明确：
> - 本装置定位为**小流量分布式制氢单元**（面向便携传感器、教育演示、应急点火/实验用氢）
> - 并给出**放大路线**（聚光倍率、催化剂负载、反应器面积 → 产氢量线性/亚线性放大曲线）
> - 现场答辩时主动把"1 mL/h"讲成"模块化堆叠可扩展"，把短板变成设计思路

## 2. 逐题深度解析

### 2.1 题目①《可见光催化富氢水一体化制备装置的研制及产氢—溶解氢传质耦合动力学建模》

| 项 | 内容 |
|---|---|
| **研究侧重点** | 装置研制（光催化产氢 → 溶解 → 富氢水收集）+ 产氢与溶解氢传质耦合建模 + 富氢水浓度控制 |
| **应用场景定位** | **健康/饮用水产品**（家用富氢水、便携健康场景） |
| **技术路线** | 催化剂（借用）→ 装置搭建 → 产氢速率测试 → 溶解氢浓度与衰减曲线 → 传质模型 → 富氢水制备工艺优化 |
| **创新点** | ① 产氢—溶解氢传质耦合建模 ② 装置集成氢浓度实时监测 ③ 面向健康应用的一体化集成 |
| **与常见研究方向匹配** | 氢分子生物医学、功能水、健康工程、光催化产氢 |
| **技术合理性（量纲）** | ✅ 优（需氢量小，匹配光催化微量产氢） |
| **跑题风险** | **高**。"富氢水"是健康产品概念，能源评审极易判定为"保健品营销"而非能源创新；且富氢水功效宣称已被监管收紧 |

**开题风险**：导师/评审第一问就是"这是能源课题还是保健品课题？"；第二问是"富氢水的健康价值有共识吗？"——两个问题都答不好就出局。
**实验推进风险**：低（浓度测试用碘量法或检测仪即可）；但若加入细胞实验则工作量陡增。
**论文撰写风险**：**高**。引言必须写富氢水价值 → 极易滑向健康宣称 → 触碰"不能写治疗/疗效"的红线 → 能源期刊/能源评审不买账。
**综合判断**：**不用于本赛**。但它是三个题目中**在后续赛道价值最高的**（生医工竞赛/挑战杯/大创的医工交叉叙事）。

### 2.2 题目②《面向便携供氢的可见光催化产氢—溶解氢一体化装置研制与传质动力学建模》

| 项 | 内容 |
|---|---|
| **研究侧重点** | 装置一体化研制 + 传质动力学建模 + **便携供氢场景适配**（体积/功耗/流量） |
| **应用场景定位** | **清洁能源 / 便携供氢**（户外、应急、分布式、燃料电池供氢） |
| **技术路线** | 同①，但多一项"供氢流量与场景需求的匹配分析"与"便携化设计（体积/功耗/重量）" |
| **创新点** | ① 产氢—溶解氢传质耦合建模 ② 装置一体化与便携化设计 ③ 面向供氢场景的参数优化 |
| **与常见研究方向匹配** | 氢能储运、便携能源、应急供氢、光催化制氢 |
| **技术合理性（量纲）** | ❌ **差**——产氢 1.1 mL/h vs 用氢 600–6000 mL/h，差 2–3 个数量级 |
| **跑题风险** | **低**。"供氢"是标准能源系统概念，完全在赛道内 |

**开题风险**：中高。评审必问"你这个产氢量能供什么？"——若答不上来，会被认为是"为了便携而便携"的包装。
**实验推进风险**：中。除了常规实验，还要做"流量—场景匹配"演示（比如给一个小型传感器/点火器供氢），增加工作量。
**论文撰写风险**：中。"应用前景分析"若不做量纲论证会显得空洞；做实了反而成为亮点。
**综合判断**：**可作本赛备选**，前提是补上 §1.3 的量纲论证与放大路线。它比①稳、比③有应用色彩，适合评审明确偏好"应用落地/经济性"的场合（细则初评确实写"可行性和经济性"）。

### 2.3 题目③《可见光催化分解水产氢装置的研制及产氢—溶解氢传质耦合动力学建模》

| 项 | 内容 |
|---|---|
| **研究侧重点** | 装置研制 + **产氢—溶解氢—逸出三段耦合传质建模**（纯科学问题） |
| **应用场景定位** | 可再生能源制氢（太阳能制氢），不承诺具体终端产品 |
| **技术路线** | 催化剂 → 装置 → 产氢速率响应面 → 溶解氢浓度衰减 → 传质系数辨识 → 模型验证 |
| **创新点** | ① 产氢—溶解氢传质耦合建模（理论，**这是护城河**）② 装置集成氢浓度实时监测（工程） |
| **与常见研究方向匹配** | 光催化分解水产氢、太阳能制氢、气液传质、反应工程 |
| **技术合理性（量纲）** | ✅ 不涉及（无应用承诺，无技术债） |
| **跑题风险** | **零** |

**开题风险**：低。唯一的追问是"创新点在哪？不就是个常规装置吗？"——答案就是传质耦合建模这个理论点。
**实验推进风险**：**最低**（无细胞实验、无流量匹配演示，纯装置+测试+建模）。
**论文撰写风险**：低。但要把理论点写实（模型形式、参数辨识方法、误差评估、与文献实测对比），否则显得单薄。
**⚠️ 一个术语风险**：题目写"**分解水**产氢"，若实验用了牺牲剂（甲醇/三乙醇胺），严格说不是"分解水"而是"光催化产氢"。评审可能挑刺。两种处理：
- **稳妥**：题目改为《可见光催化产氢装置的研制及产氢—溶解氢传质耦合动力学建模》（去掉"分解水"三字）
- **或**：真做全分解水体系（纯水，无牺牲剂），并在说明书如实写产氢速率（会低 1–2 个数量级，但不影响传质建模结论）

**综合判断**：**本赛首选**。零跑题、零技术债、工作量最小、创新点最硬。

## 6. 落地建议：无论选哪个都要补的三件事

1. **把传质耦合建模做实**（这是唯一的护城河，三个题目共享）
   - 明确模型形式：H₂ 从液相本体 → 气液界面 → 气相的双膜传质 + 溶解度（Henry 定律）+ 零级/一级生成速率
   - 参数辨识：用实测浓度衰减曲线拟合传质系数 kLa
   - 误差评估：模型预测 vs 实测，R²、RMSE、误差分布
   - 这一节写好了，三个题目都能成立；写不好，三个题目都平庸

2. **统一处理"分解水 vs 产氢"的术语**
   - 若用牺牲剂：全篇用"光催化产氢"，题目③去掉"分解水"三字
   - 若真做纯水体系：如实报告较低的产氢速率，并说明这是全分解水的固有挑战
   - 诚实是最大的创新点保护

3. **准备一页"技术合理性"附录**（无论选②还是③）
   - 产氢能力量纲表（装置产氢 1.1 mL/h）
   - 各应用需氢量对比（富氢水 11–18 mL/L ✅；燃料电池 600–6000 mL/h ❌）
   - 放大路线（催化剂负载、聚光倍率、反应器面积 → 产氢量曲线）
   - **主动把这一页放进答辩 PPT**，比被评审问倒好一百倍

## 7. 最终推荐

> **本赛选 ③《可见光催化产氢装置的研制及产氢—溶解氢传质耦合动力学建模》**（建议去掉"分解水"三字，除非真做纯水体系）。

> 4. **创新点最硬**——传质耦合建模是真理论点，可支撑学术水平评分
